# Habit Tracker PRO

A desktop productivity app built with Python.

## Features
- Add / delete habits
- XP system
- Level system
- Streak tracking
- Progress visualization
- Statistics panel
- Graph of progress

## Tech Stack
- Python
- Tkinter (GUI)
- Matplotlib (charts)
- JSON storage

## Why this project
This project was built to practice:
- software architecture
- UI development
- state management
- basic data persistence

```bash
python gui.py
